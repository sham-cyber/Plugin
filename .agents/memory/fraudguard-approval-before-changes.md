---
name: Approval before project changes
description: The user's project-specific instruction to get approval before making changes.
---

Before changing project files or Git state, obtain the user's explicit approval for the proposed scope. This includes edits, commits, history changes, and pushes.

**Why:** the user explicitly requested approval before any change.

**How to apply:** explain the planned changes and consequences first, then wait for approval before editing or taking Git actions.
